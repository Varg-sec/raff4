# Read logical files backed by maps and image streams

Local ID: AFF4-011

Type: AFK · Area: logical

## What to build

Complete logical-reader storage coverage so file consumers use one stream interface regardless of backing representation.

## Acceptance criteria

- [ ] Read direct and indirect logical stream references, shared maps and ImageStream-backed files.
- [ ] Test several files sharing storage without leaking adjacent file bytes; reject missing and cyclic references.
- [ ] Exercise seek and bounded reads for each representation in Rust.
- [ ] Report supported and unsupported storage capabilities explicitly; run the complete mandatory reader fixture matrix.

## Blocked by

- AFF4-004
- AFF4-005
- AFF4-009

## Evidence and delivery

Use the pinned baseline established in AFF4-001 and the source index in docs/design.md. Add an end-to-end fixture demonstrating this capability, record unsupported cases, and update the conformance matrix. The initial implementation and acceptance tests are Rust-only. Python bindings are deferred to AFF4-024 after the Rust core release candidate.
