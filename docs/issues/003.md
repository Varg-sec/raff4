# Read and seek uncompressed AFF4 image streams

Local ID: AFF4-003

Type: AFK · Area: reader

## What to build

Let either language read an image incrementally and seek without materializing the complete image.

## Acceptance criteria

- [ ] Read chunk indexes and multiple bevies through the public stream API, using the pinned base profile.
- [ ] Verify zero-length images, partial final chunks, boundary-crossing reads, EOF and large offsets against expected bytes.
- [ ] Reject truncated indexes, out-of-range segments and integer overflow with contextual errors.
- [ ] Demonstrate bounded cache use and Python read/seek/tell behavior on the same fixture.

## Blocked by

- AFF4-002

## Evidence and delivery

Use the pinned baseline established in AFF4-001 and the source index in docs/design.md. Add an end-to-end fixture demonstrating this capability, record unsupported cases, and update the conformance matrix. Bindings must delegate format behavior to the Rust core.
