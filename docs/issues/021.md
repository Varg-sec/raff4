# Harden public readers against malformed containers

Local ID: AFF4-021

Type: AFK · Area: quality

## What to build

Turn adversarial input handling into a repeatable release gate exercised through public APIs.

## Acceptance criteria

- [ ] Fuzz ZIP metadata, Turtle, chunk indexes, maps and stream dispatch; retain minimized regressions.
- [ ] Apply caller-configurable budgets for decompression, triples, recursion, allocations and open handles.
- [ ] Test panics, structured error propagation, lifetime misuse, cancellation and truncated containers.
- [ ] Run pinned pyaff4 and aff4tools interoperability checks with explicit unsupported-feature accounting; c-aff4 covers the shared base subset.

## Evidence and delivery

Use the pinned baseline established in AFF4-001 and the source index in docs/design.md. Add an end-to-end fixture demonstrating this capability, record unsupported cases, and update the conformance matrix. The initial implementation and acceptance tests are Rust-only. Python bindings are deferred to AFF4-024 after the Rust core release candidate.
