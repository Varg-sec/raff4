# Create a logical container with ZIP-backed files

Local ID: AFF4-013

Type: AFK · Area: writer

## What to build

Create an acquisition from caller-provided file metadata and byte streams, then reopen and verify it in Rust and Python.

## Acceptance criteria

- [ ] Preserve raw names and acquisition hierarchy; assign stable resource identities independently of paths.
- [ ] Emit the selected logical profile with required stream and metadata integrity records.
- [ ] Support stored and deflated files, empty files and folders; fail explicitly on invalid input or interrupted finalization.
- [ ] Round-trip metadata and bytes and validate output with a pinned independent reader; do not read arbitrary host paths implicitly.

- AFF4-012

## Evidence and delivery

Use the pinned baseline established in AFF4-001 and the source index in docs/design.md. Add an end-to-end fixture demonstrating this capability, record unsupported cases, and update the conformance matrix. Bindings must delegate format behavior to the Rust core.
