# Browse logical acquisitions and read ZIP-backed files

Local ID: AFF4-009

Type: AFK · Area: logical

## What to build

Allow Rust callers to browse a logical acquisition and stream an individual file without extraction.

## Acceptance criteria

- [ ] Expose file/folder identity, parentage, acquisition roots, names, timestamps and source path separators as metadata.
- [ ] Distinguish identity from display paths; preserve duplicate names and raw filename bytes.
- [ ] Support ZipSegment streams using stored/deflate members, including empty files and safe handling of hostile paths.
- [ ] Verify fixtures with non-UTF-8 names, control bytes and multiple roots; return metadata without creating host filesystem paths.

## Blocked by

- AFF4-002

## Evidence and delivery

Use the pinned baseline established in AFF4-001 and the source index in docs/design.md. Add an end-to-end fixture demonstrating this capability, record unsupported cases, and update the conformance matrix. The initial implementation and acceptance tests are Rust-only. Python bindings are deferred to AFF4-024 after the Rust core release candidate.
