# Read compressed AFF4 image streams

Local ID: AFF4-004

Type: AFK · Area: reader

## What to build

Read compressed physical images through the existing Rust stream APIs.

## Acceptance criteria

- [ ] Implement every mandatory compression method in the pinned profile and explicitly report unsupported optional methods.
- [ ] Cover deflate and Snappy fixtures where specified; resolve raw versus framed encoding using fixture evidence.
- [ ] Test mixed compressed/uncompressed chunks, partial final chunks and seeks across bevies.
- [ ] Enforce decompressed-size and cache limits and reject corrupt compressed data without uncontrolled allocation.

## Blocked by

- AFF4-003

## Evidence and delivery

Use the pinned baseline established in AFF4-001 and the source index in docs/design.md. Add an end-to-end fixture demonstrating this capability, record unsupported cases, and update the conformance matrix. The initial implementation and acceptance tests are Rust-only. Python bindings are deferred to AFF4-024 after the Rust core release candidate.
