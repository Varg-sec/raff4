# Read sparse and mapped physical images

Local ID: AFF4-005

Type: AFK · Area: reader

## What to build

Expose logical bytes from maps, including target switching and special ranges, through normal stream reads in both languages.

## Acceptance criteria

- [ ] Resolve map entries and target indexes, including symbolic streams required by the pinned profile.
- [ ] Test sparse gaps, unreadable ranges, boundaries and multiple targets; never silently invent bytes for undefined ranges.
- [ ] Detect cyclic maps, missing targets, overlapping or invalid ranges, and overflow.
- [ ] Compare sequential and random reads with canonical expected output; compressed targets use the same resolver when available.

## Blocked by

- AFF4-003

## Evidence and delivery

Use the pinned baseline established in AFF4-001 and the source index in docs/design.md. Add an end-to-end fixture demonstrating this capability, record unsupported cases, and update the conformance matrix. Bindings must delegate format behavior to the Rust core.
