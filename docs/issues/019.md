# Add optional accelerated metadata support

Local ID: AFF4-019

Type: AFK · Area: optional

## What to build

Offer a feature-gated accelerated metadata path, with equivalent observable results to the normal reader.

## Acceptance criteria

- [ ] Implement the exact pinned AFF4/HDT dialect and compare all queries with the Turtle graph.
- [ ] Test Unicode, embedded NUL, corrupt dictionaries and incomplete aggregate metadata.
- [ ] Specify integrity and fallback policy so stale acceleration data cannot silently change results.
- [ ] Expose capability information in both languages and benchmark on millions of synthetic objects before enabling by default.

## Blocked by

- AFF4-018

## Evidence and delivery

Use the pinned baseline established in AFF4-001 and the source index in docs/design.md. Add an end-to-end fixture demonstrating this capability, record unsupported cases, and update the conformance matrix. Bindings must delegate format behavior to the Rust core.
