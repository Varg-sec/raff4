# Read inline data, alternate streams and extended attributes

Local ID: AFF4-010

Type: AFK · Area: logical

## What to build

Read small resident content and secondary file streams through the same Rust/Python object model.

## Acceptance criteria

- [ ] Expose inline bytes, alternate data streams and extended attributes while preserving their association and names.
- [ ] Resolve the draft spelling and size boundary decisions from the pinned baseline; test boundary and malformed base64 cases.
- [ ] Enumerate multiple secondary streams and retain unknown metadata without collapsing distinct objects.
- [ ] Demonstrate byte-exact results from independent fixtures through both APIs.

## Blocked by

- AFF4-009

## Evidence and delivery

Use the pinned baseline established in AFF4-001 and the source index in docs/design.md. Add an end-to-end fixture demonstrating this capability, record unsupported cases, and update the conformance matrix. Bindings must delegate format behavior to the Rust core.
