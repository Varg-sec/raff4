# Write compressed and sparse physical images

Local ID: AFF4-008

Type: AFK · Area: writer

## What to build

Allow callers to choose supported compression and provide sparse ranges while preserving image semantics.

## Acceptance criteria

- [ ] Round-trip each supported compression mode, sparse ranges and multi-target maps through Rust.
- [ ] Produce all required map and content hashes and verify using the existing report API.
- [ ] Reject conflicting ranges and unsupported options before corrupt output is committed.
- [ ] Compare output with an independent reader and document throughput, compression ratio and peak memory.

## Blocked by

- AFF4-004
- AFF4-005
- AFF4-007

## Evidence and delivery

Use the pinned baseline established in AFF4-001 and the source index in docs/design.md. Add an end-to-end fixture demonstrating this capability, record unsupported cases, and update the conformance matrix. The initial implementation and acceptance tests are Rust-only. Python bindings are deferred to AFF4-024 after the Rust core release candidate.
