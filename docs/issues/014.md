# Write inline content and file substreams

Local ID: AFF4-014

Type: AFK · Area: writer

## What to build

Allow callers to preserve tiny content, alternate streams and extended attributes when writing logical acquisitions.

## Acceptance criteria

- [ ] Round-trip named secondary streams and inline payloads with explicit storage choice and validated size limits.
- [ ] Update integrity records after final serialization and verify changes through the public report API.
- [ ] Expose equivalent Rust and Python writer operations and document ownership of input buffers.
- [ ] Test unsupported metadata and oversize inputs without silently discarding data.

## Blocked by

- AFF4-010
- AFF4-013

## Evidence and delivery

Use the pinned baseline established in AFF4-001 and the source index in docs/design.md. Add an end-to-end fixture demonstrating this capability, record unsupported cases, and update the conformance matrix. Bindings must delegate format behavior to the Rust core.
