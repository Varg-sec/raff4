# Ship Rust documentation and reproducible Python wheels

Local ID: AFF4-022

Type: AFK · Area: release

## What to build

Deliver an installable release candidate with verifiable functionality and a clearly bounded conformance statement.

## Acceptance criteria

- [ ] Publish build artifacts for agreed Linux, macOS and Windows/Python targets; test imports and real fixture operations from installed wheels.
- [ ] Generate and check Python type stubs from the binding surface; document read, write, seek, verify and error handling in both languages.
- [ ] Run the conformance matrix and report skipped optional capabilities, provenance and exact standard revisions.
- [ ] Confirm package names and license, remove publish=false only when release-ready, and document versioning and compatibility policy; actual registry publication is a separate release action.

- AFF4-018
- AFF4-021

## Evidence and delivery

Use the pinned baseline established in AFF4-001 and the source index in docs/design.md. Add an end-to-end fixture demonstrating this capability, record unsupported cases, and update the conformance matrix. Bindings must delegate format behavior to the Rust core.
