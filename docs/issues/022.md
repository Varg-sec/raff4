# Ship a documented Rust release candidate

Local ID: AFF4-022

Type: AFK · Area: release

## What to build

Deliver an installable release candidate with verifiable functionality and a clearly bounded conformance statement.

## Acceptance criteria

- [ ] Validate library builds and fixture operations on the agreed Linux, macOS and Windows targets, including the selected minimum Rust version.
- [ ] Build Rust API documentation and executable examples for read, write, seek, verify and error handling; validate the Cargo package contents.
- [ ] Run the conformance matrix and report skipped optional capabilities, provenance and exact standard revisions.
- [ ] Confirm package names and Apache-2.0 license metadata, remove publish=false only when release-ready, and document versioning and compatibility policy; actual registry publication is a separate release action.

## Blocked by

- AFF4-018
- AFF4-021

## Evidence and delivery

Use the pinned baseline established in AFF4-001 and the source index in docs/design.md. Add an end-to-end fixture demonstrating this capability, record unsupported cases, and update the conformance matrix. The initial implementation and acceptance tests are Rust-only. Python bindings are deferred to AFF4-024 after the Rust core release candidate.
