# Read and write imported metadata stores

Local ID: AFF4-018

Type: AFK · Area: scaling

## What to build

Support acquisitions whose object metadata is distributed across stores while preserving one queryable graph.

## Acceptance criteria

- [ ] Round-trip a partitioned acquisition through Rust enumeration and content reads.
- [ ] Verify imported store hashes and primary metadata integrity; reject unresolved or cyclic imports with a bounded traversal.
- [ ] Restrict resolution to caller-supplied containers; do not fetch remote IRIs implicitly.
- [ ] Test conflicting triples, duplicate imports and corruption; measure open time and memory on a generated large corpus.

## Blocked by

- AFF4-012
- AFF4-013

## Evidence and delivery

Use the pinned baseline established in AFF4-001 and the source index in docs/design.md. Add an end-to-end fixture demonstrating this capability, record unsupported cases, and update the conformance matrix. The initial implementation and acceptance tests are Rust-only. Python bindings are deferred to AFF4-024 after the Rust core release candidate.
