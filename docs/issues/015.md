# Write large logical files and shared storage

Local ID: AFF4-015

Type: AFK · Area: writer

## What to build

Write large logical files using chunked storage and optionally share identical content across files.

## Acceptance criteria

- [ ] Choose storage explicitly or through a documented policy; avoid buffering entire files.
- [ ] Emit maps and all required hashes, and round-trip random reads across boundaries.
- [ ] Test shared content, empty files and collision handling; deduplication never equates unequal content solely on a weak digest.
- [ ] Verify through both APIs and an independent implementation; report memory and size measurements.

## Evidence and delivery

Use the pinned baseline established in AFF4-001 and the source index in docs/design.md. Add an end-to-end fixture demonstrating this capability, record unsupported cases, and update the conformance matrix. Bindings must delegate format behavior to the Rust core.
